# Neon GeoQuiz Arena

A Leaflet.js geography guessing game with Firebase Firestore global leaderboard.

## Files
- index.html
- style.css
- script.js
- firestore.rules

## Quick start
1. Open `script.js`.
2. Replace the Firebase placeholder config with your Firebase web app config.
3. Create a Firestore database in Firebase.
4. Paste `firestore.rules` into Firestore Rules and publish.
5. Open `index.html` locally, or deploy the folder to Firebase Hosting.

## Notes
The geography question pool is paraphrased and exam-inspired, not copied from official exam papers.
